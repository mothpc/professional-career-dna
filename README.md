# Professional Career DNA

An open-source, AI-assisted career intelligence skill collection for discovering professional identity, exploring career opportunities, and planning development through conversation and evidence.

**Status:** Product discovery completed; documentation foundation under review. No installable skills or renderer are released yet.

The planned v0.1.0 release includes career-discovery, professional-dna, career-positioning, career-growth and career-report. Career reflection follows in v0.2.0.

## Principles

Conversation first; evidence over title; verify, don't assume; reflection rather than flattery; user-owned Markdown; model-independent instructions; deterministic reports. This is a personal development tool, not a hiring assessment, psychometric test or professional certification.
