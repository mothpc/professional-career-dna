# Accepted product decisions

Date: 2026-11-26. All 13 decisions below were agreed during product discovery. Implementation details remain open unless explicitly specified.

| ID | Decision | Accepted direction |
|---|---|---|
| 001 | Product identity | Career intelligence skill collection; reflection companion philosophy |
| 002 | Domain and model independence | Domain-agnostic core, extensible guidance; agent-driven research |
| 003 | Persistence | Markdown source of truth; JSON derived for report rendering |
| 004 | Skill boundaries | Six independently invocable outcome-oriented skills |
| 005 | Assessment | Adaptive dimensions and common evidence rubric; distinguish similarity, readiness, preference and confidence |
| 006 | Interview | Adaptive conversation with coverage tracking; one question at a time |
| 007 | Research | Context-aware research with mandatory verification; verify, don't assume |
| 008 | Lifecycle | Living documents and milestone snapshots |
| 009 | Reporting | Adaptive content and deterministic rendering; mobile-first HTML and A4 PDF |
| 010 | Execution | Progressive disclosure; no custom orchestration engine |
| 011 | Privacy | User-controlled disclosure; private and shareable reports; no built-in telemetry |
| 012 | Evaluation | Scenario-based outcome rubric; deterministic artifact tests |
| 013 | MVP | Five core skills in v0.1.0; reflection in v0.2.0 |

See [architecture decisions](adr/README.md) for grouped architectural implications. Product and behavioral decisions remain normative even when not represented by a separate ADR.
