# ADR 0002 — User-owned Markdown workspace

Status: Accepted direction (decisions 003, 008).

Context: Conversation memory alone is not portable; JSON-only is harder for people to edit. Overwrite-only loses history.

Decision: Markdown living documents are canonical, with confirmed immutable milestone snapshots. JSON is derived for reports. Skills share documents, not mandatory calls.

Consequences: Human-readable portable state and history; requires ownership boundaries, confirmation and consistency checks. Exact schema/versioning remain open.
