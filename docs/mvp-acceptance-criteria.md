# MVP acceptance criteria

Target v0.1.0. All gates are pending implementation and verification.

- [ ] Five core skills are independently invocable, with documented prerequisites and fallbacks.
- [ ] End-to-end discovery to report succeeds with a fictional profile and user confirmation.
- [ ] Every substantive assessment has evidence, rationale and uncertainty; public claims are verified and cited.
- [ ] Adaptive competency model works for technology and at least one non-technology scenario.
- [ ] At least two agent environments are exercised; actual compatibility and limitations documented.
- [ ] Markdown updates preserve confirmed facts and milestone snapshots; JSON remains derived.
- [ ] No real private data or telemetry in repository/fixtures; shareable outputs exclude unapproved content.
- [ ] Offline mobile-first HTML and A4 PDF render correctly with direct chart labels and readable pagination.
- [ ] Scenario-based evaluations and deterministic artifact checks meet reviewed thresholds; no unresolved critical failures.
- [ ] README documents tested installation, invocation, examples, prerequisites and limitations.

## Release boundaries

Reflection skill and historical comparison are deferred to v0.2.0. No backend, database, hiring scoring, model training, or custom orchestration. Implementation and release are not authorized by this documentation PR alone.

## Before implementation

Resolve rubric anchors and aggregation, report schema/renderer, Markdown contract details, per-host packaging and evaluation thresholds in focused reviewable decisions. Then derive implementation issues from the accepted specification.
