# Agent development instructions

Read the product specification, decision register and relevant contracts before changing the project. Accepted decisions are constraints; propose changes explicitly and document their rationale. Do not infer approval of open technical decisions. Keep skills concise and independently invocable; use progressive disclosure. Do not add a backend, orchestration engine or provider dependency without a reviewed scope change.

Verify claims against evidence; distinguish facts, inferences and unknowns. Use fictional fixtures only. Never publish real career workspaces, confidential employer information or sensitive reports. Do not add telemetry. Do not claim cross-platform support or successful validation without actual test evidence.

Use focused branches and reviewable pull requests. Keep documentation aligned with implementation; include tests for behavior and artifacts where relevant. Do not merge without maintainer approval. Current phase is documentation only.
